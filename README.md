# Rozvrhy

Webová aplikace na tvorbu hezkých školních rozvrhů.

Aktuálně umí mimo jiné:
- načítat starší JSON exporty,
- kopírovat celé políčko tlačítkem i přes Ctrl+C / Ctrl+V,
- měnit barvu předmětu globálně ve všech jeho výskytech,
- upravovat font, velikost a umístění obsahu políček,
- automaticky zmenšovat dvojice a trojice objektů; případně je lze nastavit ručně zvlášť,
- měnit emoji jednotlivých dnů,
- zobrazovat dole legendu učitelů,
- exportovat celý rozvrh do JPG a PDF bez ořezu.

Hlavní stránka je `index.html`.
